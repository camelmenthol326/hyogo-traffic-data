# 兵庫県 交通取締り公開データ

兵庫県警察が公開する交通指導取締り計画PDFから、日付・地区・路線名・取締り内容だけを抽出し、iPhoneアプリが読み取れるJSONへ変換します。

## 公開データ

- JSON: `data/traffic-data.json`
- 更新時刻: 原則として毎日8:00、12:00、17:00（日本時間）
- 出典: [兵庫県警察 交通取締情報](https://www.police.pref.hyogo.lg.jp/traffic/violation/jyouho/index.htm)

GitHub Actionsの実行時刻は混雑などにより遅れる場合があります。

## 注意事項

- 予定は変更される場合があり、掲載場所以外でも取締りは行われます。
- 公開PDFの地区は市町村や実施区間を正確に示すものではありません。
- 兵庫県警察のロゴ、画像、PDF、ページデザインは収録しません。
- 本リポジトリおよび利用アプリは、兵庫県警察の公式・公認ではありません。
- 位置情報や利用者情報は収集しません。
